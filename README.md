# Свадебное приглашение — Алина & Александр

Готовый статический сайт без сборщика и серверной части.

## Запуск
Откройте `index.html` в браузере.

## Что уже реализовано
- стартовый экран с состаренным бумажным конвертом: в центре мягко пульсирует свечение, по клику / Enter / Space верхний клапан вместе с восковой печатью (оттиск «А & А») открывается на 3D-шарнире, под ней проявляются золотые обручальные кольца;
- автоматический переход к основному сайту через ~1 секунду после открытия;
- романтический стиль в духе референса: молочный фон, шалфейные оттенки, тонкая типографика, ботанический декор;
- адаптация под телефон;
- блок истории пары;
- расписание 12:00 / 17:00;
- место проведения: ресторан «Чистые пруды», Киевская ул., 80, Симферополь;
- RED CARPET;
- блок «Вместо цветов»;
- обратный отсчёт до 31 октября 2026, 12:00 (UTC+3);
- плавное появление элементов при прокрутке.
